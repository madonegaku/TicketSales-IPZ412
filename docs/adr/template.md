# ADR-NNN. Назва рішення

| Поле | Значення |
| --- | --- |
| **Номер** | ADR-NNN |
| **Статус** | Запропоновано / Прийнято / Замінено ADR-00M / Відхилено |
| **Дата** | РРРР-ММ-ДД |
| **Відповідальний** | ПІБ (роль) |
| **Учасники обговорення** | ПІБ, ПІБ, ПІБ |
| **Замінює** | ADR-00N (якщо запис переглядає попереднє рішення) |

## Контекст

Проблема, обмеження та вимоги (з посиланнями на сценарії якості), що зумовили потребу в рішенні.

## Розглянуті варіанти

Щонайменше два альтернативні варіанти з їх оцінкою.

1. **Варіант 1** – переваги, недоліки, оцінка.
2. **Варіант 2** – переваги, недоліки, оцінка.
